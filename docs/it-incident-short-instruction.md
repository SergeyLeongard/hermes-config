# Короткая инструкция: как заводить ИТ-инцидент

1. Одно сообщение = одна проблема: кратко опишите, что именно не работает.
2. Укажите контекст: где проблема (`1С`, почта, сеть/VPN, ПК, принтер, камеры) и когда началась.
3. Если есть ошибка, добавьте точный текст/скриншот и ваши шаги перед сбоем.
4. Не смешивайте несколько разных вопросов в одном сообщении — для новой темы отправляйте отдельное.
5. Не-ИТ вопросы (быт/хозчасть) отправляйте вне IT-диспетчера.
